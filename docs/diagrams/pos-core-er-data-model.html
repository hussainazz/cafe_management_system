ER / DATA MODEL

Cafe POS Transaction Core

The v1 order aggregate is centered on immutable order snapshots and posted settlement records. Supporting catalog, table, audit, idempotency, session, reversal, and settings tables are summarized below to keep this ER view within the plugin budget.

Immutable Snapshot Boundary

`OrderItem` and `OrderItemOption` retain product, option, price, discount, and preparation snapshots so later catalog edits never rewrite receipts or historical totals.

Posted Payment Boundary

`PaymentSettlement`, `SettlementAllocation`, and `Payment` are append-only in normal flows. Corrections use full settlement reversal instead of editing posted rows.

DATA FLOW

Staff POS Order To Settlement

The POS backend flow keeps price calculation, idempotency, settlement allocation, payment-status derivation, and audit writes inside the Fastify service and PostgreSQL transaction boundary.

Authoritative Calculation

The POS sends product selections, quantities, tender inputs, and expected versions. The API calculates prices, discounts, timing, settlement totals, paid amount, balance, and payment status.

Transaction Boundary

Order creation and settlement recording commit business rows, idempotency records, version increments, and audit entries atomically before any receipt-ready read is served.
